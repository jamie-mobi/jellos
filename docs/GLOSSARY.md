# Glossary

One name per thing. UI text, code comments, docs, and errors use these words only.

| Term | Means | Not |
| --- | --- | --- |
| Server | A Jellyfin server the app connects to by address | host, instance, backend |
| Address | The server's URL, for example `http://192.168.1.10:8096` | URL (in UI text), endpoint |
| Demo Content | The built-in mock library; needs no server | sample data, mock, offline mode |
| User | An account on a server | profile, account (except "account menu") |
| Account menu | The toolbar menu with the signed-in user's avatar | profile menu, user menu |
| Sign In / Sign Out | Start or end a user's session on a server | log in, log out, connect |
| Switch User | Go back to the user picker without signing out | change user, log in as |
| Library | A top-level collection on the server, for example Movies or Shows | view, folder, collection |
| Home | The page with Continue Watching, Next Up, and Latest shelves | dashboard, start |
| Item | Any movie, series, season, or episode | media, content, title (in code) |
| Movie / Series / Season / Episode | The item types | show (use Series), film |
| Shelf | A horizontal row of items on Home or a detail page | row, rail, carousel |
| Continue Watching | Items with a saved position | resume, in progress |
| Next Up | The next unplayed episode of each series being watched | up next, queue |
| Latest | Items added most recently to a library | recently added, new |
| Favorites | Items the user marked with the heart | likes, starred |
| Played | The item has been watched to the end | watched, seen, complete |
| Mark Played / Mark Unplayed | Set or clear Played | mark watched |
| Add to Favorites / Remove from Favorites | Set or clear the heart | favorite, like |
| Poster | The 2:3 cover image of a movie, series, or season | cover, artwork |
| Thumbnail | The 16:9 image of an episode or Continue Watching item | still, thumb |
| Backdrop | The full-width image behind a detail page or the Home hero | background, fanart |
| Cast & Crew | The people on an item: actors, directors, writers | people, credits |
| More Like This | Items similar to the open item | recommended, similar |
| Featured | The large item at the top of Home, one of up to 10 pages | hero, banner, spotlight (in UI text) |
| See All | The full grid opened from a shelf header chevron | view all, more |
| Collection | A Jellyfin BoxSet: a named set of items, for example a film series | bundle, playlist (and not a Library) |
| Genre | A genre name from the server, for example Comedy | category |
| Top Rated | The 10 items with the highest community rating, shown with ranks | top 10, chart |
| For You | Items picked from what the user played | recommended, suggestions |
| Trailers | Local or remote trailers of an item | previews |
| Extras | An item's special features: behind the scenes, featurettes | bonus content, specials |
| Added this week | Caption on an item added in the last 7 days | new, just added |
