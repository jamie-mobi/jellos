  <b>jellyOS</b>  A ground up re imagine of the amazing work from the peeps behind <a href="https://github.com/jellyfin/swiftfin">Jellyfin(https://github.com/jellyfin/swiftfin)</a> media server.
</p>

### NOTE

This is I am a work in progress and/or a prototype. Do not expect this to work out of the box. There is a lot of work to do to get a working application running. Feel free to download and play around, but at this stage no support will be given until the application is in a stable position and I can work out what contributing looks like if you wish.

### Why am I doing this

I work for Kick and specifically around the tvOS project. There has been a lot of work and lessons learned working on that application, which I would love to apply here. This is not to diminish the work by the SwiftFin community, as it was the inspiration for starting this project. This is a passion project of someone who wants to disconnect from streaming services and own my own content.
